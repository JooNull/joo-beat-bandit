# Bandit Level 1 → Level 2

> The password for Level 2 is stored in a file named `-` located in the home directory.

## Steps

1. **List Files:** Run `ls` to locate the file named `-` in the home directory.
2. **Read the File:** Run `cat ./-` to display the file contents and retrieve the password for Level 2. The `./` prefix ensures `-` is interpreted as a filename rather than a special argument.
