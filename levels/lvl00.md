# Bandit Level 0

> The goal of this level is to connect to the Bandit server using SSH on port 2220.

## Steps

1. **Connect via SSH:** Use `ssh bandit0@bandit.labs.overthewire.org -p 2220` to establish an SSH connection to the Bandit server.
2. **Authenticate:** Enter the provided password `bandit0` when prompted to log in successfully.
