# Bandit Level 3 → Level 4

> The password for Level 4 is stored in a hidden file inside the `inhere` directory.

## Steps

1. **Navigate to Directory:** Run `cd inhere/` to enter the `inhere` directory.
2. **List Hidden Files:** Run `ls -aF` to display all files, including hidden ones. The `-a` option shows hidden files, while `-F` appends indicators to file types.
3. **Read the File:** Run `cat ...Hiding-From-You` to display the file contents and retrieve the password for Level 4.
